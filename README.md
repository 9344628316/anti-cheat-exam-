# Online Anti-Cheat Exam System

## About the Project
This project is an online anti-cheat exam website developed using HTML, CSS, JavaScript, and Firebase.  
The system helps conduct secure online examinations with anti-cheating features and automatic monitoring.

## Live Website
https://anticheatexam-fdb43.web.app/

## Features
- Online examination system
- User authentication
- Admin dashboard
- Timer-based exam system
- Automatic result generation
- Responsive design
- Prevents tab switching during exams
- Detects screenshots and automatically closes the exam
- Secure exam environment

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Firebase

## Project Files
- `index.html`
- `exam.html`
- `results.html`
- `admin.html`
- `exam.js`
- `admin.js`
- `auth.js`
- `firebase.js`
- `styling.css`

## Purpose
The purpose of this project is to create a secure online examination platform with anti-cheating features and improve frontend and backend web development skills.
